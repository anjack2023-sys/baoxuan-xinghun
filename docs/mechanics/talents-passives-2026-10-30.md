# 八螺天赋与被动 · 2026-10-30

本方案替换旧版被动，保留全部主动技能及其解锁条件。旧技能文档中的被动章节由本文覆盖。
固定天赋沿用 skills-grade1.csv 的 passive 槽（兼容现有16行读取器）；条件被动在 SkillRuntime.h 实现，图鉴文案在 SkillBalance.h。

| 陀螺 | 固定天赋 | 条件被动 |
|---|---|---|
| 赤锋 | 锋锐：攻击+10% | 破阵：3秒未碰对手后，下次主动撞击额外推力+20%；碰对手重新计时 |
| 炽纹 | 炽心：攻击+6%、自然衰减-4% | 燎原：主动撞击攻击+4%，最多3层，持续2.5秒；刷新时间，超时全部清空 |
| 壁垒 | 厚壁：防御+10% | 蓄震：受击3次，下次主动撞击额外推力+20%；储备期间不再蓄积，消耗时不同时蓄积 |
| 煌铠 | 金甲：碰撞击退-8% | 守界：外圈防御+12%；外圈受击获得15%击退减免1.5秒，冷却6秒 |
| 长旋 | 绵延：自然衰减-8% | 静息：3秒无碰对手、墙、障碍，自然衰减再降12%；碰撞中断 |

| 衡刃 | 均衡：攻击、防御各+5% | 转势：主动撞击防御+10%，受击攻击+10%，持续2秒，互相替换；同时对撞优先防御 |
| 霜环 | 冷衡：防御+5%、自然衰减-5% | 寒蚀：主动撞击令对手自然衰减+10%，持续3秒，冷却5秒 |

## 结算

- 新被动以有效接近碰撞（Closing>0）为前提。碰撞前自身速度在朝向对手的法线投影>0时计主动撞击，对手计受击；正面对撞可双方都计。必须分离后再次接触才能再次计数。
- 主动技能仍沿用原有双方碰撞次数规则，不改变5/10/15/20门槛。
- 乘区相乘；同一被动不重复叠加，炽纹层数除外。霜环主动和被动同时存在时对手自然衰减×1.12×1.10。
- 自然衰减、碰撞转速损失、耐久磨损分别结算。翠磐天赋只降低碰撞转速损失，不降低耐久磨损。
- 击退减免作用于碰撞冲量，不提供出界免疫、不减少自然衰减。
- 全部计时、层数、冷却、小局强化状态每局重置。物理基准常数和现有主动效果不变。
- 条件被动在碰撞结算后生效，对后续物理步产生影响。
