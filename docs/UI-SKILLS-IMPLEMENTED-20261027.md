## 数值来源与机制

权威仍为 `docs/balance/skills-grade1.csv`，同步镜像 `Content/Beyblade/Data/skills-grade1.csv`。原来的主倍率、技能条件没有改；把说明中的持续时间与第二效果落成 `duration_s`、`secondary_key`、`secondary_value` 三列，供程序读取。引擎先读 Content，失败再查 docs；完整 16 行才接入，否则报错并禁用技能。日志为 `SKILL_DATA rows=16 source=...`。`Config/DefaultGame.ini` 增加 Data 原始文件随包分发设置，尚未重新制作工业独立发行包验证。

`SkillBalance.h` 负责读表；`SkillRuntime.h` 负责条件、被动、释放和恢复。保留现有类名供调用者兼容，不再只是视觉按钮壳。

| 螺 | 实现 |
|---|---|
| 赤锋 | 被动攻击×1.10；主动攻击×1.20、3s，并增加出击推力偏置 |
| 炽纹 | 碰撞后攻击×1.08、2s；主动下一次追加冲量×1.35，碰撞后消耗 |
| 壁垒 | 被动防御×1.08；主动防御×1.25、3.5s |
| 煌铠 | 外圈防御×1.12；主动下一次受击冲量/磨损×0.75并回抛25%，命中后消耗 |
| 长旋 | 被动衰减×0.92；主动衰减×0.75、4s |
| 翠磐 | 被动磨损×0.88；主动质量×1.15、5s，技能质量增益同时降低所受碰撞速度变化 |
| 衡刃 | 被动攻防质量×1.05；主动攻击×1.15、防御×1.10、3s |
| 霜环 | 被动衰减×0.95且防御×1.05；主动对手衰减×1.12、3s |

持续效果始终根据本局裸属性重新计算，结束恢复被动状态，避免越放越高。双方被动均上场生效，主动仍由玩家手动点；没有新增 AI 自动放技能。自动黄金对照模式保持不启用技能。

条件沿用表中的 5/10/15/20，释放后升档；持久只认自己的螺/墙接触并重置安静时间；均衡要求最近 N 秒内螺和墙各至少一次，过期接触不能使按钮永久就绪。所有计时改为固定仿真步进，避免帧率影响。回合结束禁止释放技能。

## 实用边界

- 五卡出战池仍是赤锋/壁垒/长旋/衡刃/炽纹。煌铠、翠磐、霜环在图鉴中可见，效果引擎和自动测试已覆盖，但不擅自扩大出战池。
- 赤锋表中的 `RingoutRateAdd=0.10` 当前解释为出击推力偏置×1.10，界面标“推力”，**不是已经校准的击飞概率+10个百分点**。以后接入完整飞行模型再标定概率。
- 煌铠原表没有持续秒数，按“下一次有效碰撞”实现减伤与回抛，没有杜撰持续时间。
- 角色、陀螺网格、工业地图、Grade1 裸属性、Feel85 常数、旧版试玩均未改动。
- 简单 CSV 读取适用于当前表；字段内不要加入逗号/换行。需要引号转义字段时应换完整 CSV 解析器。
